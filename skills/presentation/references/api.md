# Build API reference

Generated by `scripts/api_ref.py` from the code -- do not edit; run `scripts/api_ref.py --write`. Signatures and the first paragraph of each docstring. How to compose with these: `references/drawing.md`; the recipe: `SKILL.md`.

Geometry is 1/100 mm (`mm()`, `pt()`); colours are `0xRRGGBB` integers -- by name through `D.color("accent")`, never typed as hex; font sizes are points.
